# How to Add Voting Steps Videos

This folder contains videos for the "How Voting Works" section.

## Required Videos

Place your MP4 video files in this folder with these exact names:

1. **step1.mp4** - Register to Vote / Get Your Voter ID
   - Content: Video showing how to get voter ID card
   
2. **step2.mp4** - Enter the Polling Booth
   - Content: Video showing entering polling station, showing ID, getting ink mark
   
3. **step3.mp4** - Use the EVM Machine
   - Content: Video demonstrating how to use the EVM voting machine
   
4. **step4.mp4** - Your Vote is Secret
   - Content: Video explaining vote secrecy and confidentiality

## Video Specifications

- **Format**: MP4
- **Recommended Resolution**: 1280x720 (720p) or higher
- **Aspect Ratio**: 16:9
- **File Size**: Keep under 50MB per video for faster loading
- **Duration**: 30-60 seconds per video (ideal)

## File Structure

```
client/public/videos/
├── step1.mp4
├── step2.mp4
├── step3.mp4
└── step4.mp4
```

## Usage

Once you place the videos in this folder:
1. Refresh the browser
2. Navigate to "How Voting Works" 
3. Videos will auto-play (muted) when you navigate through each step
4. Users can unmute and replay using video controls

## Notes

- Videos auto-play muted to prevent audio issues
- Users can unmute using the video player controls
- Videos have standard HTML5 video controls (play, pause, volume, fullscreen)
- If a video file is missing, users will see a message
